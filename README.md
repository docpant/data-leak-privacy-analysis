# Data Leak Privacy Analysis

## Overview

This project analyzes a data leak incident involving improper sharing of confidential company documents. The investigation focuses on identifying failures related to least privilege controls and recommending improvements based on NIST SP 800-53 AC-6 guidance.

The project evaluates how excessive access permissions and poor access management contributed to the incident and proposes security enhancements to improve information privacy.

## Objective

- Analyze causes of a data leak
- Review least privilege failures
- Study NIST SP 800-53 AC-6
- Recommend access control improvements
- Justify privacy protection recommendations

## Skills Demonstrated

- Access control analysis
- Least privilege implementation
- Privacy governance
- Risk analysis
- Security documentation
- NIST framework interpretation

## Framework Referenced

- NIST SP 800-53 AC-6 (Least Privilege)

## Outcome

The project identified weaknesses in access management practices and proposed security control enhancements to reduce the likelihood of future data leaks.
